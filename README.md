# Tacticalgraphic

โครงต้นแบบระบบขายภาพดิจิทัล เริ่มจากโปรเจกต์ใหม่แยกจาก `Tactical-Studies-Section`

## สถานะ

ระยะนี้เป็นเพียงโครงสร้างและหน้าต้นแบบ (UI prototype) ยังไม่มีการเชื่อมต่อระบบสมาชิกจริง การชำระเงิน/เติมเหรียญ การหักเหรียญ การจัดส่งอีเมล หรือการสร้าง ZIP จริง ปุ่มในหน้าต้นแบบใช้แสดง flow เท่านั้น ห้ามใช้กับธุรกรรมจริง

## ขอบเขตระบบที่วางไว้

1. **คลังภาพ** — แสดงภาพตัวอย่างและรายละเอียด พร้อมเตรียมเชื่อมโฟลเดอร์ Google Drive ที่เจ้าของกำหนด: [โฟลเดอร์ภาพ](https://drive.google.com/drive/folders/1mYtAuD15F6zD9TD-dzFAUsm4GZ7KBunQ?usp=drive_link)
2. **สมาชิก** — จุดเริ่มสมัคร/เข้าสู่ระบบ แยกผู้ซื้อกับผู้ขาย โดยสถานะและเงื่อนไขสิทธิ์ยังรอกำหนด
3. **กระเป๋าเหรียญ** — วางหน้าดูยอดและประวัติเติมเครดิต/เหรียญ ยังไม่รับชำระเงินจริง
4. **เลือกและซื้อภาพ** — ตะกร้า/สรุปราคาและ flow หักเหรียญ ยังไม่ทำรายการจริง
5. **ส่งมอบภาพ** — วาง flow จัดชุด ZIP และส่งทาง Email ยังไม่สร้างไฟล์หรือส่งอีเมลจริง

## แนวทางก่อนเปิดใช้งานจริง

- กำหนดคุณสมบัติ/การอนุมัติผู้ขาย ผู้ซื้อ การคืนเงิน และข้อพิพาท
- เลือก payment provider และกำหนดอัตราแปลงเครดิตเป็นเหรียญ
- กำหนดราคา ค่าธรรมเนียม การยกเลิกรายการ และนโยบายคืนเหรียญ
- ตรวจสิทธิ์การขายและการใช้ภาพทุกไฟล์ก่อนนำเข้าคลัง; ผู้ใช้เว็บไม่ควรได้รับสิทธิ์ Drive เกินความจำเป็น
- สร้าง backend สำหรับบัญชี ยอดเหรียญ และประวัติธุรกรรม โดยตรวจสอบยอดที่ server เท่านั้น
- เก็บ payment secrets และ email credentials ใน secret manager/environment ไม่ใส่ใน frontend หรือ Git
- สร้าง ZIP ชั่วคราวอย่างปลอดภัย จำกัดอายุลิงก์ดาวน์โหลด และไม่เปิด Drive ทั้งโฟลเดอร์เป็นสาธารณะ
- เพิ่มบันทึกตรวจสอบ (audit log), rate limits, backup และขั้นตอนช่วยเหลือผู้ซื้อ

## เริ่มต้น

เปิด `index.html` ใน browser เพื่อดูหน้าต้นแบบ ไม่ต้องติดตั้ง dependencies

## ความเป็นส่วนตัว

Repository นี้ตั้งเป็น Private ยังไม่มีการคัดลอกโค้ดหรือข้อมูลจากระบบเดิมเข้ามา
